TÀI LIỆU ĐẶC TẢ API DATABASE SERVER (API SPECIFICATION)
DỰ ÁN: WORKLIFE MANAGER - QUẢN LÝ CÔNG VIỆC & SINH HOẠT
Phiên bản: 1.0.0
Định dạng: RESTful JSON API
Mã hóa: UTF-8
Chuẩn xác thực: Bearer Token (JWT)
Base URL: https://api.worklifemanager.com/v1

I. TỔNG QUAN CHUẨN KẾT NỐI VÀ HEADER
--------------------------------------------------------------------------------
Mọi request gửi lên server cần có Header:
  - Content-Type: application/json
  - Accept: application/json
  - Authorization: Bearer <jwt_access_token> (bắt buộc cho các route bảo vệ)

Cấu trúc Response chuẩn của Server:
  Thành công (2xx):
  {
    "success": true,
    "code": 200,
    "message": "Thành công",
    "data": { ... } // hoặc mảng [ ... ]
  }

  Thất bại (4xx, 5xx):
  {
    "success": false,
    "code": 400,
    "error": "BAD_REQUEST",
    "message": "Mô tả chi tiết lỗi",
    "details": [ ... ]
  }

II. NHÓM 1: AUTHENTICATION & USER SETTINGS (XÁC THỰC VÀ TÀI KHOẢN)
================================================================================

1. Đăng ký tài khoản
  - Method: POST
  - Endpoint: /auth/register
  - Request Body:
    {
      "email": "user@example.com",
      "password": "Password123@",
      "full_name": "Nguyễn Lê Anh Đức",
      "avatar_url": "https://..." (optional)
    }
  - Response 201 Created:
    {
      "success": true,
      "code": 201,
      "message": "Đăng ký thành công",
      "data": {
        "user_id": "usr_99182a",
        "email": "user@example.com",
        "full_name": "Nguyễn Lê Anh Đức",
        "token": "eyJhbGciOi..."
      }
    }

2. Đăng nhập tài khoản
  - Method: POST
  - Endpoint: /auth/login
  - Request Body:
    {
      "email": "user@example.com",
      "password": "Password123@"
    }
  - Response 200 OK:
    {
      "success": true,
      "code": 200,
      "message": "Đăng nhập thành công",
      "data": {
        "access_token": "eyJhbGciOi...",
        "token_type": "Bearer",
        "expires_in": 86400,
        "user": {
          "id": "usr_99182a",
          "email": "user@example.com",
          "full_name": "Nguyễn Lê Anh Đức",

          "theme_mode": "system", // "light", "dark", "system"
          "currency": "VND",
          "reminder_enabled": true,
          "auto_sync": true
        }
      }
    }

3. Lấy thông tin cá nhân & cài đặt

  - Endpoint: /user/profile
  - Response 200 OK:

      "code": 200,

    + to_date: "2026-10-31"
    + category: "Dự án" | "Học tập" | "Họp" | "Khác"
    + is_completed: true | false
    + search: "Tên công việc"
    + page: 1
    + limit: 20

    {

      "code": 200,

            "title": "Phát triển giao diện Flutter Desktop & Mobile",

            "end_time": "2026-10-04T18:00:00Z",

VI. NHÓM 5: CHỈ BÁO LỊCH THU NHỎ (MINI CALENDAR INDICATORS)
================================================================================

1. Lấy trạng thái chỉ báo chấm màu cho lịch theo tháng/năm
  - Method: GET
  - Endpoint: /calendar/indicators?year=2026&month=10
  - Query Params:
    + year: integer (2026)
    + month: integer (1 - 12)
  - Quy tắc logic trả về:
    + has_uncompleted_task (Đỏ): Ngày đó có ít nhất 1 công việc chưa đạt 100% hoàn thành.
    + has_all_completed_task (Xanh lá): Ngày đó có công việc và TẤT CẢ công việc đã đạt 100%.
    + has_expense (Vàng Gold): Ngày đó có phát sinh sinh hoạt / chi tiêu.
  - Response 200 OK:
    {
      "success": true,
      "code": 200,
      "data": {
        "year": 2026,
        "month": 10,
        "days": [
          {
            "date": "2026-10-01",
            "has_task": true,
            "all_tasks_completed": true, // Dot màu xanh lá
            "has_expense": true,         // Dot màu vàng gold
            "task_count": 3,
            "expense_count": 2
          },
          {
            "date": "2026-10-04",
            "has_task": true,
            "all_tasks_completed": false, // Dot màu đỏ (vì còn việc chưa xong)
            "has_expense": true,          // Dot màu vàng gold
            "task_count": 4,
            "expense_count": 1
          },
          {
            "date": "2026-10-08",
            "has_task": false,
            "all_tasks_completed": false,
            "has_expense": true,          // Dot màu vàng gold

VIII. MÃ LỖI THƯỜNG GẶP (HTTP STATUS CODES)
================================================================================
- 200 OK: Yêu cầu xử lý thành công.
- 201 Created: Tạo tài nguyên mới thành công.
- 400 Bad Request: Dữ liệu gửi lên không đúng định dạng (thiếu trường bắt buộc, ngày giờ sai chuẩn ISO).
- 401 Unauthorized: Thiếu JWT Token hoặc Token hết hạn.
- 403 Forbidden: Không có quyền truy cập dữ liệu của user khác.
- 404 Not Found: Không tìm thấy ID công việc hoặc sinh hoạt.
- 500 Internal Server Error: Lỗi cơ sở dữ liệu server.
